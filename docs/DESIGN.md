# Campus Desk interface

Audience: a student with an immediate IT problem. Task: ask a short question, read the next step, check the exact handbook source.

Operate/Read surface: a wide answer workspace beside a narrower, browsable handbook. The signature interaction is a source button that opens and focuses its supporting article in the handbook. Mobile puts the handbook below the answer. A decorative hero was rejected in favor of giving the question field the first useful space.

Colors: paper #f8fafc, white #ffffff, navy #162c45, blue #1957a6, blue wash #eaf1fa, muted slate #526479, amber #ffc64b (demo notice). Georgia gives the opening one human voice; Avenir Next / system sans handles the working interface. No external fonts or assets, no analytics. Visible focus, live status, labelled fields, safe text rendering, restrained waiting animation with reduced-motion support. The fictional-data notice stays visible in the header and below the answer.
