# Campus Desk — โน้ตส่งต่องาน Q1

โครงงานนี้ช่วยนักศึกษาหาขั้นตอนแก้ปัญหา IT และเปิดบทความที่ใช้อ้างอิงได้ โดยใช้คู่มือมหาวิทยาลัยสมมติ 16 บทความ ต้องบอกผู้ชมให้ชัดว่า **ไม่ใช่นโยบายจริงของ KMITL** และข้อมูลกับคำถามทดสอบสร้างโดยมี AI ช่วย ยังไม่ได้ตรวจโดยเจ้าหน้าที่มหาวิทยาลัย

## เปิดใช้งาน

ทำตาม README เพื่อสร้าง `.venv` ติดตั้ง `requirements.lock` และใส่ key ของ class proxy ใน `.env` จากนั้นเรียก `./run.sh` แล้วเปิด http://127.0.0.1:8765

## สาธิตสั้น ๆ

1. กด New phone แล้วกด Find an answer ระบบควรแนะนำใช้ backup code และลงทะเบียน authenticator ใหม่
2. กดชื่อแหล่งอ้างอิงใต้คำตอบ บทความทางขวาจะเปิดให้ตรวจรายละเอียด
3. เปิด View handbook lookups อธิบายว่าโมเดลเลือกค้นคู่มือหรืออ่านบทความได้ แต่เครื่องมือทำงานได้เฉพาะรายการที่อนุญาต
4. ลองถามเรื่องที่ไม่มีในคู่มือ เช่น “Which medicine should I take for a fever?” ระบบควรบอกว่าไม่ทราบจากคู่มือ
5. แสดงข้อจำกัดจริง: offline test-03 และ test-14 มีบทความที่เกี่ยวข้อง แต่คะแนนต่ำกว่าเกณฑ์ ส่วน live injection case ถูกปฏิเสธเพราะ arguments ผิด schema จึงไม่ตอบ Wi-Fi ได้สำเร็จ

## อธิบายตัวเลข

ชุด development 10 ข้อใช้เลือก threshold เท่านั้น ชุด test 30 ข้อแยกเป็นคำถามตอบได้ 26 และนอกขอบเขต 4 ข้อ แยกตามคำถาม ไม่ได้แยกหัวข้อ

- BM25: ค้นบทความที่ถูกใน 3 อันดับแรกได้ 25/26; ปฏิเสธข้อที่ไม่มีคำตอบถูก 2/4; ตัดสินใจรวมถูก 27/30
- Hybrid ไม่ตั้ง threshold: ค้นถูก 26/26 แต่ยังปฏิเสธได้ 2/4
- Hybrid threshold 0.30 ที่เลือกจาก development: ค้นถูก 24/26 แต่ปฏิเสธได้ 4/4 รวม 28/30

เหตุผลของ threshold คือยอมพลาดบางคำถามเพื่อไม่ส่งบทความที่เกี่ยวข้องน้อยไปให้โมเดล ตัวเลข 28/30 เป็นคะแนนการตัดสินใจด้าน retrieval **ไม่ใช่ความถูกต้องของคำตอบ LLM** และความต่างเพียง 1 ข้อยังไม่ยืนยันนัยสำคัญทางสถิติ

Live smoke test รุ่นแรก 5/8 และรุ่นที่สอง 7/8 ใช้แก้ความเข้ากันได้กับ proxy จึงไม่ใช่ held-out benchmark การผ่านตรวจเพียง status กับ reference ID ไม่ได้พิสูจน์ว่าทุกประโยคมีหลักฐานรองรับ อุณหภูมิ 0 ก็ยังอาจได้ผลต่างเมื่อเรียกใหม่

## จุดที่ควรอ่านก่อนตอบอาจารย์

`app/agent.py` คือ loop และ stop condition; `app/schemas.py` ตรวจรูปแบบ; `app/tool_arguments.py` แปลงรูปแบบ native ของ Gemma อย่างจำกัด; `app/retrieval.py` คำนวณ TF-IDF/BM25; `evaluation/run.py` คำนวณ metric; `data/README.md` อธิบายที่มาข้อมูล

ระบบนี้ไม่มี shell tool และไม่มีการรีเซ็ตบัญชีหรือคืนเงินจริง API key อยู่ใน environment เท่านั้น การตรวจ citation เป็นเพียงตรวจว่า ID มาจากบทความที่ค้นเจอ ไม่ได้ตรวจ entailment อัตโนมัติ

Q1 เป็น URL repository ส่วนรายงาน PDF และวิดีโอ/เว็บที่ deploy คือ Q2/Q3 ซึ่งเป็นงานแยกกัน
